# DeepSim

محاكي عميق (Deep Simulation) للعبة **Kaggriculture** على Kaggle — يُستخدم لتقييم قرارات الوكيل قبل اتخاذها، بهدف تحسين الأداء إلى ما فوق $120,000.

## الفكرة الأساسية

بدلاً من إعادة كتابة قواعد اللعبة (خطر الانحراف عن المحرك الحقيقي)، المحاكي يلفّ **المحرك الرسمي نفسه** الموجود داخل `kaggle_environments`:

```
kaggle_environments/envs/kaggriculture/kaggriculture.py
```

نستدعي دالة `interpreter()` مباشرة على كائنات خفيفة (stubs)، متجاوزين طبقة تشغيل الوكلاء والتسلسل الثقيلة في `kaggle_environments`. النتيجة:

- **دقة 100%**: نفس قواعد اللعبة، السوق، الطلب البلدي، الأعشاب، تدفقات RNG، وترتيب المعالجة.
- **سرعة**: ~48ms للحلقة الكاملة (720 turn) مقابل ~2s+ للمشغّل الرسمي.

## الهيكل

```
DeepSim/
├── main.py                 ← نقطة الدخول (الوكيل الحقيقي)

│   ├── simulator.py        ← المحاكي السريع فوق المحرك الرسمي
│   ├── market_model.py     ← إسقاط الأسعار/المخزون بدقة (يستخدم دالة سعر المحرك نفسها)

│   ├── constants.py / economy.py / planner.py / ...  ← الوكيل الإنتاجي (لا يُلمس)
│   └── adapter.py          ← (لاحقاً) ربط المحاكي بالوكيل أثناء اللعب
├── tests/
│   ├── test_simulator.py   ← اختبارات التحقق
│   ├── vs_ghosts.py        ← معيار ضد أشباح القادة
│   └── analyze_worst_seed.py ← تشخيص أسوأ بذرة
├── overview/               ← قواعد اللعبة والتوثيق الرسمي
└── replays/                ← بيانات القادة ووكيلنا
```

## الاستخدام

```python
from src.simulator import Simulator, evaluate, parity_check
from main import Agent

# حلقة كاملة واحدة
res = Simulator(seed=42).run([Agent(), "pass"])
print(res["money"])    # [our_money, opp_money]
print(res["winner"])   # 0 / 1 / None (tie)

# تقييم دفعة كاملة على عدة بذور
stats = evaluate(lambda: Agent(), seeds=range(30), opponent="pass")
print(stats["mean"], stats["best"], stats["worst"])

# التحقق من التطابق مع المشغّل الرسمي
worst_diff, _ = parity_check([0, 1, 2], opponent="pass")
assert worst_diff == 0
```

من سطر الأوامر:

```bash
python -m src.simulator --seeds 5 --parity      # فحص سريع + تطابق
python -m src.simulator --seeds 30              # معيار كامل
python -m unittest tests.test_simulator -v      # الاختبارات
```

## المنافسون المتاحون

| الاسم | الوصف |
|-------|-------|
| `"pass"` | وكيل سلبي (PASS فقط) — أساس المقارنة |
| `"random"` | الوكيل العشوائي المدمج في المحرك |
| أي callable | `agent(obs) -> action_dict` (مثلاً نسخة أخرى من وكيلنا) |

## تحليل الـreplays الحية (13 مباراة من السلّم)

سجلنا: **6W-7L**. الخصوم الذين هزمنا يتبعون نمطاً واضحاً:

| المؤشر | الخصوم الأقوياء | وكيلنا (في الخسائر) |
|--------|------------------|---------------------|
| شراء أبقار | **17/لعبة** | 6 |
| أغنام | 7 | 12 |
| سماد مباع | **528** | 272 |
| بذور قمح مشتراة | 60 | 195 |

الاستنتاج: اقتصاد **بقري ثقيل** — البقرة تنتج كل يومين ($160+) وتضاعف تدفق السماد. التجارب:
- `KAGG_COW_PLAN="COW:SHEEP"` toggle في `economy.py` (OFF = الأساس)
- 18:0 انهار ($69.7k) — تنويع الصوف ضروري
- **15:3 + CropAdvisor هو التوازن الأمثل**: أعلى متوسط محمي الأسوأ حالة
| **CropAdvisor (`KAGG_CROP_ADVISOR=1`)** | **$86,338** ✅ | $96,513 | $60,810 |

**مستشار المحاصيل — التقرير النهائي (v9):**
- المتوسط: **$86,338 (+$851)**، سجل **3 فوز / 0 خسارة / 27 تعادل** — يحقق المعايير الثلاثة
- أسوأ بذرة (11): **+$18,748** ($42k → $60.8k)
- آلية العمل: خلف `KAGG_CROP_ADVISOR=1` فقط؛ يراقب السعر المسقط للفراولة عند الحصاد، وإذا انخفض تحت $190 **بعد يوم 12** يقود البطيخ الزراعة مؤقتاً
- دروس المعايرة (v1-v8 مرفوضة):
  1. ROI الدورة الواحدة يبالغ في تفضيل البطيخ (يتجاهل إغراقنا الذاتي للسوق) → -$2,700
  2. القرار قبل يوم 10 عديم الإشارة: كل العوالم متطابقة ~$160-170 لأن متاجر قليلة فُكّت → خسائر زائفة -$11.7k
  3. اليوم 12 هو الفاصل: عوالم التعافي تكشف نفسها برسمة متجر يوم 12

**دروس مستفادة من التجارب:**

1. **إسقاط "الاستهلاك البلدي فقط" متفائل منهجياً**: يتجاهل إنتاجنا المستقبلي وأثر مبيعاتنا الذاتية على المخزون.
2. **البذور الخاسرة سببها أسعار منتجات منهارة** (متاجر عشوائية ضارة).
3. **وكيلنا يبيع السماد أكثر من القادة أصلاً** (~276/لعبة مقابل 200-240) — فرضية "بيع المزيد من السماد" مستبعدة.
4. بوابات البيع اليدوية في `economy.py` (bull/bail/YARN-regime) قوية جداً — أي نموذج عام يجب أن يضاهيها قبل الاستبدال.

## ملاحظات تقنية

- **البذرة**: تحدد أعشاباً عشوائية وفكّ المتاجر (`seed * 1000003 ^ day`) — نفس البذرة = نفس النتيجة حرفياً.
- **الأداء الحالي**: ~21 حلقة/ثانية للمحاكي الخالص، ~2.5 حلقة/ثانية مع وكيلنا (زمن الوكيل هو عنق الزجاجة).
- **مباريات المرآة** (`tests/mirror_bench.py`): وكيلنا ضد نفسه ي reproduces ضغط السلّم (اللبن ينهدار إلى ~$105-121 مقابل $135+ منفرداً). A/B تحت الضغط: WHEAT=30 يساوي **+$8.7k** في المرآة (أكثر من المنفرد!)، 15:3 يحتفظ بأعلى متوسط.
- **حد Kaggle**: الوكيل النهائي ≤ 100 MiB.
